# LTE Firmware OTA — Implementation Plan + Test Matrix

> Execute SoftAP-proven `fw_ota` + new LTE pull path. Test every row before calling Phase 2 done.

**Goal:** Modular LTE OTA client using QHTTP GET → `fw_ota`.

**Architecture:** `net_lte` transport; `fw_ota_lte` policy/orchestration; SoftAP trigger; lab server + ngrok.

---

### Task 1: `net_lte` HTTP GET APIs

**Files:** `components/net_lte/include/net_lte.h`, `net_lte.c`

- [ ] `net_lte_http_get(url, buf, buf_len, out_len, result)` — small responses (manifest)
- [ ] `net_lte_http_get_stream(url, chunk_cb, ctx, result)` — CONNECT then stream `content_length` bytes
- [ ] Enlarge UART RX buffer for stream path (or document 16KB install)
- [ ] Build

### Task 2: `fw_ota_lte` component

**Files:** `components/fw_ota_lte/*`

- [ ] NVS load/save manifest URL, channel, force
- [ ] `fw_ota_lte_run()` — fetch manifest, decide, stream bin, reboot
- [ ] Background task starter for SoftAP (don’t block httpd)
- [ ] Status: idle/checking/downloading/failed/no_update + last error

### Task 3: SoftAP + boot wiring

**Files:** `http_api.c`, `static_index.html.h`, `app_main.c`, CMakeLists

- [ ] `/api/ota/lte` GET/POST, `/api/ota/lte/run` POST

### Task 4: Lab server + ngrok ready

- [ ] Publish current `.bin` under `tools/ota_dev_server/firmware/<ver>/`

## Test matrix (all cases)

| ID | Case | Setup | Expected |
|----|------|-------|----------|
| T1 | SoftAP A↔B still works | Upload via web | Partition flips (regression) |
| T2 | Manifest reachable over LTE | ngrok up; `Run LTE OTA` with force off, same version | `no_update` or skip; no reboot |
| T3 | Happy path LTE update | Bump version string or force=1; same bin OK with force | Download, reboot other slot, confirm |
| T4 | Bad SHA-256 | Manifest sha wrong | Abort; stay on current slot |
| T5 | Truncated / fail mid-GET | Kill ngrok mid-download | `failed`; boot unchanged |
| T6 | Wrong/unreachable URL | Bad manifest URL | `failed` with clear error |
| T7 | LTE down | Modem detach / SIM out | `failed` PDP/UART; no flash |
| T8 | Concurrent SoftAP upload | Start LTE run then SoftAP POST | One busy (`409` / invalid state) |
| T9 | Power-loss story (lab) | Unplug mid-download if safe | Still boots previous app |
| T10 | Rollback path | Optional: flash known-bad image SoftAP | Pending verify fail → rollback (manual) |

**Pass criteria:** T1–T8 green on bench; T9/T10 documented if not run.
