# UL212 RS-232 Fetch (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On Seeed XIAO ESP32-C6, read Tenet UL212 over RS-232 (MAX232) and print decoded height / temp / tilt / signal on USB serial, with compile-time protocol 14 (default) or 51.

**Architecture:** Tiny PlatformIO Arduino app. Pure parse helpers + UART driver (`ul212_rs232`) + thin `main` loop. No Zigbee/BLE/NVS. Protocol selected via `UL212_RS232_PROTOCOL` in `ul212_rs232_config.h`.

**Tech Stack:** PlatformIO, Arduino-ESP32, HardwareSerial UART1, USB CDC 115200.

**Spec:** `docs/superpowers/specs/2026-09-04-ul212-rs232-fetch-design.md`

## Global Constraints

- Board default: `seeed_xiao_esp32c6`
- No Zigbee, no FleetZigbee, no custom Zigbee partitions in Phase 1
- Default protocol **14**; alternate **51** via `#define UL212_RS232_PROTOCOL`
- Sensor address default **1** (`UL212_RS232_ADDRESS`)
- Baud **9600 8N1** on sensor UART; USB monitor **115200**
- Clear names and short comments; no dead code
- Lab reference: `hardware/fleet_telematics_carrier/host/ul212-wired-fetch/NOTES.md`

```c
#include <stdio.h>
#include <math.h>
#include <string.h>
#include "ul212_rs232_parse.h"

static int fails;

static void expect_true(int cond, const char *msg) {
  if (!cond) { printf("FAIL: %s\n", msg); fails++; }
  else printf("OK: %s\n", msg);
}

int main(void) {
  Ul212Reading r;
  expect_true(ul212ParseXd("*XD,4850,20,0364,2300,0363,0651,1005#", &r), "parse xd");
  expect_true(r.valid, "xd valid");
  expect_true(fabsf(r.smooth_mm - 36.4f) < 0.05f, "smooth");
  expect_true(fabsf(r.height_mm - 36.3f) < 0.05f, "height");
  expect_true(fabsf(r.temp_c - 25.1f) < 0.05f, "temp");
  expect_true(r.signal == 23, "signal");
  expect_true(r.tilt_deg == 5, "tilt");

  memset(&r, 0, sizeof(r));
  expect_true(ul212ParseCfv("*CFV0100016CA4\r\n", &r), "parse cfv");
  expect_true(fabsf(r.height_mm - 1.6f) < 0.05f, "cfv height");

  expect_true(!ul212ParseXd("garbage", &r), "reject garbage");
  return fails ? 1 : 0;
}
```

- [ ] **Step 3: Implement `src/ul212_rs232_parse.c`**

Parse `*XD,…#` fields as in NOTES / design (comma-separated):  
`ver, extra, smooth, signalCodes, realtime, tempRaw, trailer`  
- `smooth_mm = atoi(smooth)/10.0`  
- `height_mm = atoi(realtime)/10.0`  
- `signal = first two digits of signalCodes` (e.g. `2300` → 23)  
- `temp_c = (atoi(tempRaw) - 400) / 10.0`  
- `tilt_deg = strtol(last two chars of trailer, 16)`  

Parse `*CFV`: after `*CFV`, two-digit addr, five-digit raw height → `height_mm = raw/10.0`.

Zero unused fields; set `valid = true` on success.

- Produces:
  - `void ul212Rs232Begin(int rx_pin, int tx_pin, uint32_t baud = 9600);`

- [ ] **Step 1: Write `ul212_rs232.h`**

```cpp
#include <stdint.h>
```

- [ ] **Step 2: Implement `ul212_rs232.cpp`**

- `HardwareSerial SensorUart(1);`
- `begin(baud, SERIAL_8N1, rx, tx)`
- Build command: `snprintf(cmd, …, "$!RY%02u%02u\r\n", addr, protocol)` with addr/protocol from config
- Flush/drain carefully: for protocol 14 do **not** wipe a buffer that already has `*XD`
- Write cmd, read into a line buffer until `#` (14) or `\n` (51) or timeout
- Call `ul212ParseXd` / `ul212ParseCfv`; set `stamp_ms = millis()`
- On failure return zeroed reading with `valid = false`

### Task 4: `main.cpp` print loop

**Files:**
- Modify: `hardware/fleet_telematics_carrier/host/ul212-rs232-fetch/src/main.cpp`

**Interfaces:**
- Consumes: `ul212Rs232Begin`, `ul212Rs232Poll`, `board_pins.h`, `ul212_rs232_config.h`

- [ ] **Step 1: Replace stub main**

```cpp
#include <Arduino.h>
#include "board_pins.h"
#include "ul212_rs232.h"
#include "ul212_rs232_config.h"

void setup() {
  Serial.begin(115200);
  delay(1500);
  Serial.println("=== UL212 RS-232 fetch (XIAO ESP32-C6) ===");
  Serial.printf("protocol=%d address=%d RX=%d TX=%d\n",
                UL212_RS232_PROTOCOL, UL212_RS232_ADDRESS,
                UL212_UART_RX_PIN, UL212_UART_TX_PIN);
  ul212Rs232Begin(UL212_UART_RX_PIN, UL212_UART_TX_PIN, 9600);
}

void loop() {
  Ul212Reading r = ul212Rs232Poll(1000);
  if (r.valid) {
    Serial.printf("height=%.1f mm  smooth=%.1f mm  temp=%.1f C  tilt=%u deg  signal=%u\n",
                  r.height_mm, r.smooth_mm, r.temp_c, r.tilt_deg, r.signal);
  } else {
    Serial.println("(no frame)");
  }
#if UL212_RS232_PROTOCOL == 51
  delay(200);
#else
  delay(500);  /* listen cadence; sensor may push ~8–10 s */
#endif
}
```
